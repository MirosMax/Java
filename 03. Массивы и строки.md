## Одномерные массивы

### Объявление и создание

Два эквивалентных синтаксиса объявления:

```java
int[] arr1;   // предпочтительный
int arr2[];   // допустимый, из C-стиля
```

Создание через `new` с указанием размера (размер фиксирован и не меняется):

```java
int[] numbers = new int[5];   // массив из 5 int, значения 0
```

### Инициализация

Литерал с одновременным созданием:

```java
int[] primes = {2, 3, 5, 7, 11};
String[] names = {"Аня", "Боря"};
```

Можно и без литерала:

```java
int[] arr = new int[]{1, 2, 3};   // анонимный литерал
```

### Индексация

Индексы от 0 до `length - 1`. Выход за границы — `ArrayIndexOutOfBoundsException`.

```java
int[] arr = {10, 20, 30};
arr[0]          // 10
arr[1] = 25;    // присваивание элементу
// arr[3]       // ArrayIndexOutOfBoundsException
```

### `length`

Поле массива (не метод!):

```java
int[] arr = new int[10];
arr.length // 10
```

### Значения по умолчанию

Элементы автоматически инициализируются по типу: числа — 0, `boolean` — false, ссылки — null (см. [[01. Основы языка Java#Значения по умолчанию|значения по умолчанию]]).

```java
double[] d = new double[3]; // {0.0, 0.0, 0.0}
String[] s = new String[2]; // {null, null}
```

## Многомерные массивы

### Массивы массивов

В Java многомерный массив — это массив массивов. Каждый «ряд» — отдельный объект.

```java
int[][] grid = new int[3][4];   // 3 ряда по 4 элемента
```

### Прямоугольные массивы

Все ряды одной длины:

```java
int[][] m = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
m[1][2] // 6
```

### Ступенчатые массивы

Ряды разной длины:

```java
int[][] jagged = new int[3][];
jagged[0] = new int[2];
jagged[1] = new int[5];
jagged[2] = new int[3];
```

Многомерные массивы можно перебирать enhanced `for`:

```java
for (int[] row : m) {
    for (int v : row) System.out.print(v + " ");
}
```

## Массивы ссылочных типов

Массив хранит ссылки на объекты. Элементы по умолчанию `null`.

```java
String[] words = {"a", "b"};
String[] copy = words;         // копия ссылки, тот же массив
words[0] = "z";
copy[0]                        // "z" — общий объект
```

## Передача массивов в методы

Массивы передаются по значению ссылки: метод видит тот же массив и может менять его содержимое (см. [[04. Методы и параметры#Передача по значению|передачу по значению]]).

```java
void fill(int[] a, int value) {
    for (int i = 0; i < a.length; i++) a[i] = value;
}

int[] arr = new int[3];
fill(arr, 7);        // arr теперь {7, 7, 7}
```

## Возвращение массивов из методов

```java
int[] range(int from, int to) {
    int[] result = new int[to - from + 1];
    for (int i = 0; i < result.length; i++) result[i] = from + i;
    return result;
}

int[] r = range(1, 5); // {1, 2, 3, 4, 5}
```

Возврат массива не копирует его — возвращается ссылка.

## Копирование массивов

### `clone`

Копирует одномерный массив (поверхностно). Для ссылочных типов копируются ссылки, не объекты.

```java
int[] original = {1, 2, 3};
int[] copy = original.clone();   // независимый массив
copy[0] = 99;
original[0]                      // 1 — не изменился
```

### `System.arraycopy`

Низкоуровневое копирование участка: источник, старт, приёмник, старт, длина.

```java
int[] src = {1, 2, 3, 4, 5};
int[] dst = new int[5];
System.arraycopy(src, 1, dst, 0, 3);   // dst: {2, 3, 4, 0, 0}
```

Может копировать в тот же массив со смещением (сдвиг внутри массива).

### `Arrays.copyOf` и `copyOfRange`

Удобные обёртки над `System.arraycopy`.

```java
int[] a = {1, 2, 3};
int[] b = Arrays.copyOf(a, 5);   // {1, 2, 3, 0, 0} — расширение
int[] c = Arrays.copyOfRange(a, 1, 3); // {2, 3}
```

## Класс `Arrays`

Статические утилиты для работы с массивами.

### Сортировка

```java
int[] a = {3, 1, 2};
Arrays.sort(a);          // {1, 2, 3}

String[] s = {"b", "a"};
Arrays.sort(s);          // сортировка в естественном порядке
```

Для объектов — сортировка через `Comparable`/`Comparator` (см. [[10. Коллекции и структуры данных#Сортировка|сортировку коллекций]]).

### Поиск

Бинарный поиск по отсортированному массиву; возвращает индекс или отрицательное значение (точка вставки) при отсутствии.

```java
int[] a = {1, 2, 3, 4, 5};
Arrays.binarySearch(a, 3);   // 2
Arrays.binarySearch(a, 9);   // отрицательное (отсутствует)
```

### Сравнение

```java
int[] a = {1, 2};
int[] b = {1, 2};
Arrays.equals(a, b);     // true — поэлементно
Arrays.compare(a, b);    // 0 — лексикографически
```

Для многомерных — `deepEquals`, `deepToString`.

### Заполнение

```java
int[] a = new int[5];
Arrays.fill(a, 42);      // {42, 42, 42, 42, 42}
```

### Преобразование в строку

```java
int[] a = {1, 2, 3};
Arrays.toString(a);      // "[1, 2, 3]"
```

## Класс `String`

### Неизменяемость

Объекты `String` неизменяемы: любой «изменяющий» метод возвращает новый объект, исходный не меняется. Потокобезопасны и безопасны для передачи.

```java
String s = "abc";
String t = s.toUpperCase();  // "ABC"
s                            // "abc" — исходный не изменился
```

### String Pool

Строковые литералы и результаты конкатенации констант попадают в пул строк — кэш внутри JVM. Строки из пула переиспользуются (см. [[15. JVM, память и профессиональная разработка#Память JVM|память JVM]]).

```java
String a = "hello";         // в пуле
String b = "hello";         // тот же объект из пула
a == b                      // true (одинаковые литералы)
```

Созданная через `new` строка в пул не попадает автоматически.

### Создание строк

```java
String s1 = "hello";                    // литерал -> пул
String s2 = new String("hello");        // новый объект (обычно не нужно)
String s3 = String.valueOf(42);         // "42"
String s4 = "a" + "b";                  // конкатенация, "ab"
```

### Сравнение

#### `==`

Сравнивает ссылки — для строк обычно ошибка:

```java
String a = "hello";
String b = new String("hello");
a == b        // false — разные объекты
```

#### `equals`

Сравнивает содержимое — корректный способ:

```java
a.equals(b)   // true
```

#### `equalsIgnoreCase`

Без учёта регистра:

```java
"Hello".equalsIgnoreCase("hello")   // true
```

Идиома: `"literal".equals(value)` — безопасна при `value == null`.

### Получение символов

```java
String s = "Java";
s.charAt(0)    // 'J'
s.length()     // 4
s.codePointAt(0) // 74 (код символа)
```

### Поиск

```java
String s = "Hello, world";
s.indexOf('o')      // 4
s.indexOf("wor")    // 7
s.lastIndexOf('o')  // 8
s.indexOf('x')      // -1 — не найдено
```

### Подстроки

```java
String s = "Hello, world";
s.substring(7)      // "world"
s.substring(0, 5)   // "Hello" (endIndex исключается)
```

### Замена

```java
String s = "a-b-c";
s.replace('-', '_')      // "a_b_c" (по символу)
s.replace("-", ":")      // "a:b:c" (по последовательности)
s.replaceAll("\\d", "#") // регулярное выражение (см. [[13. Дата, время, числа и полезные API#Регулярные выражения|regex]])
```

### Разделение и склейка

```java
String csv = "a,b,c";
String[] parts = csv.split(",");    // {"a", "b", "c"}

String joined = String.join(",", "a", "b", "c"); // "a,b,c"
```

### Изменение регистра

```java
"Java".toUpperCase()    // "JAVA"
"Java".toLowerCase()    // "java"
```

### Удаление пробелов

```java
"  x  ".trim()     // "x" — только до/после
"  x  ".strip()    // "x" — то же для ASCII, корректнее для Unicode
```

`stripLeading`/`stripTrailing` убирают пробелы с одной стороны.

### Форматирование

```java
String s = String.format("%s: %d руб.", "Цена", 100); // "Цена: 100 руб."
String r = "%.2f".formatted(3.14159);                 // "3.14"
```

### Проверки `isEmpty`, `isBlank`, `startsWith`, `endsWith`, `contains`

```java
"".isEmpty()            // true
"  ".isBlank()          // true (только пробельные символы)
"Java".startsWith("Ja") // true
"Java".endsWith("va")   // true
"Hello".contains("ell") // true
```

## `StringBuilder`

### Назначение и изменяемость

`StringBuilder` — изменяемая последовательность символов. Многократная конкатенация строк в цикле создаёт кучу промежуточных объектов; `StringBuilder` этого избегает.

```java
// плохо: в цикле создаётся много String
String s = "";
for (int i = 0; i < 1000; i++) s += i;

// хорошо
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) sb.append(i);
String result = sb.toString();
```

### `append`, `insert`, `delete`, `replace`, `reverse`, `toString`

```java
StringBuilder sb = new StringBuilder("Java");
sb.append(" 21");          // "Java 21"
sb.insert(4, " SE");       // "Java SE 21"
sb.delete(4, 7);           // "Java21"
sb.replace(0, 4, "JDK");   // "JDK21"
sb.reverse();              // "12KDJ"
String s = sb.toString();  // неизменяемая строка
```

## `StringBuffer`

### Отличия от `StringBuilder`

`StringBuffer` — потокобезопасный аналог `StringBuilder` (методы синхронизированы). API одинаковый.

### Потокобезопасность

`StringBuffer` использует синхронизацию, поэтому медленнее. В однопоточном коде всегда предпочтителен `StringBuilder`; `StringBuffer` оправдан только при разделении между потоками (см. [[14. Многопоточность и конкурентность#Синхронизация|синхронизацию]]).

| | `StringBuilder` | `StringBuffer` |
| --- | --- | --- |
| Потокобезопасность | нет | да (синхронизирован) |
| Скорость | выше | ниже |
| Когда | однопоточный код | разделяемый между потоками |

## Текстовые блоки

С Java 15 многострочные строки задаются тройными кавычками — без экранирования `\n`.

```java
String json = """
    {
      "name": "Java",
      "version": 21
    }
    """;
```

- Отступы: общий отступ всех строк автоматически убирается (по крайнему левому непустому символу).
- Закрывающие `"""` определяют базовый отступ.
- Служебные пробелы можно управлять: `\` в конце строки убирает перевод строки, `\s` — неразрывный пробел.

```java
String sql = """
    SELECT id, name
    FROM users
    WHERE active = true
    """;
```

Подробнее о работе со строками и производительности — [[10. Коллекции и структуры данных#List|списки]] (как динамическая альтернатива массивам).

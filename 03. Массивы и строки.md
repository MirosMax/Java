## Одномерные массивы

### Объявление и создание

Два эквивалентных синтаксиса объявления:

```java
int[] arr1;   // предпочтительный
int arr2[];   // допустимый, из C-стиля
```

Создание через `new` с указанием размера (размер фиксирован и не меняется):

```java
int[] numbers = new int[5];   // массив из 5 int, значения 0
```

### Инициализация

Литерал с одновременным созданием:

```java
int[] primes = {2, 3, 5, 7, 11};
String[] names = {"Аня", "Боря"};
```

Можно и без литерала:

```java
int[] arr = new int[]{1, 2, 3};   // анонимный литерал
```

### Индексация

Индексы от 0 до `length - 1`. Выход за границы — `ArrayIndexOutOfBoundsException`.

```java
int[] arr = {10, 20, 30};
arr[0]          // 10
arr[1] = 25;    // присваивание элементу
// arr[3]       // ArrayIndexOutOfBoundsException
```

### `length`

Поле массива (не метод!):

```java
int[] arr = new int[10];
arr.length // 10
```

### Значения по умолчанию

Элементы автоматически инициализируются по типу: числа — 0, `boolean` — false, ссылки — null (см. [[01. Основы языка Java#Значения по умолчанию|значения по умолчанию]]).

```java
double[] d = new double[3]; // {0.0, 0.0, 0.0}
String[] s = new String[2]; // {null, null}
```

## Ковариантность массивов

Массивы в Java **ковариантны** — если `S` подтип `T`, то `S[]` подтип `T[]`. В отличие от generics (см. [[09. Обобщения и система типов#Ковариантность, контравариантность и инвариантность|инвариантность generics]]), это допускает ошибку на этапе выполнения:

```java
String[] strings = new String[3];
Object[] objects = strings;        // ковариантность — ок на этапе компиляции
objects[0] = 42;                   // ArrayStoreException на этапе выполнения!
```

JVM проверяет тип при записи. `ArrayStoreException` — runtime-защита от несоответствия типов. Если массив создан как `String[]`, туда нельзя записать ничего, кроме `String`.

**Идиома**: если нужна универсальная работа с массивами разных типов — передавать `Object[]` и проверять `instanceof` при чтении, или использовать коллекции (List).

## Многомерные массивы

### Массивы массивов

В Java многомерный массив — это массив массивов. Каждый «ряд» — отдельный объект.

```java
int[][] grid = new int[3][4];   // 3 ряда по 4 элемента
```

### Прямоугольные массивы

Все ряды одной длины:

```java
int[][] m = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
m[1][2] // 6
```

### Ступенчатые массивы

Ряды разной длины:

```java
int[][] jagged = new int[3][];
jagged[0] = new int[2];
jagged[1] = new int[5];
jagged[2] = new int[3];
```

Многомерные массивы можно перебирать enhanced `for`:

```java
for (int[] row : m) {
    for (int v : row) System.out.print(v + " ");
}
```

## Массивы ссылочных типов

Массив хранит ссылки на объекты. Элементы по умолчанию `null`.

```java
String[] words = {"a", "b"};
String[] copy = words;         // копия ссылки, тот же массив
words[0] = "z";
copy[0]                        // "z" — общий объект
```

## Передача массивов в методы

Массивы передаются по значению ссылки: метод видит тот же массив и может менять его содержимое (см. [[04. Методы и параметры#Передача по значению|передачу по значению]]).

```java
void fill(int[] a, int value) {
    for (int i = 0; i < a.length; i++) a[i] = value;
}

int[] arr = new int[3];
fill(arr, 7);        // arr теперь {7, 7, 7}
```

## Возвращение массивов из методов

```java
int[] range(int from, int to) {
    int[] result = new int[to - from + 1];
    for (int i = 0; i < result.length; i++) result[i] = from + i;
    return result;
}

int[] r = range(1, 5); // {1, 2, 3, 4, 5}
```

Возврат массива не копирует его — возвращается ссылка.

## Копирование массивов

### `clone`

Копирует одномерный массив (поверхностно). Для ссылочных типов копируются ссылки, не объекты.

```java
int[] original = {1, 2, 3};
int[] copy = original.clone();   // независимый массив
copy[0] = 99;
original[0]                      // 1 — не изменился
```

**Для многомерных массивов `clone()` — только верхний уровень**: копируются ссылки на ряды, сами ряды общие.

```java
int[][] a = {{1, 2}, {3, 4}};
int[][] b = a.clone();      // новый массив рядов
b[0][0] = 99;               // изменит и a[0][0]
```

Для полной (глубокой) копии копировать ряды вручную.

### `System.arraycopy`

Низкоуровневое копирование участка: источник, старт, приёмник, старт, длина.

```java
int[] src = {1, 2, 3, 4, 5};
int[] dst = new int[5];
System.arraycopy(src, 1, dst, 0, 3);   // dst: {2, 3, 4, 0, 0}
```

Может копировать в тот же массив со смещением (сдвиг внутри массива).

### `Arrays.copyOf` и `copyOfRange`

Удобные обёртки над `System.arraycopy`.

```java
int[] a = {1, 2, 3};
int[] b = Arrays.copyOf(a, 5);   // {1, 2, 3, 0, 0} — расширение
int[] c = Arrays.copyOfRange(a, 1, 3); // {2, 3}
```

## Класс `Arrays`

Статические утилиты для работы с массивами.

### Сортировка

```java
int[] a = {3, 1, 2};
Arrays.sort(a);          // {1, 2, 3}

String[] s = {"b", "a"};
Arrays.sort(s);          // сортировка в естественном порядке
```

Для объектов — сортировка через `Comparable`/`Comparator` (см. [[10. Коллекции и структуры данных#Сортировка|сортировку коллекций]]).

Для больших массивов — `parallelSort` (многопоточная, быстрее на больших данных):

```java
Arrays.parallelSort(largeArray);
```

### Поиск

Бинарный поиск по отсортированному массиву; возвращает индекс или отрицательное значение (точка вставки) при отсутствии.

```java
int[] a = {1, 2, 3, 4, 5};
Arrays.binarySearch(a, 3);   // 2
Arrays.binarySearch(a, 9);   // отрицательное (отсутствует)
```

### Заполнение

```java
int[] a = new int[5];
Arrays.fill(a, 42);      // {42, 42, 42, 42, 42}

// заполнение по формуле (Java 8+)
Arrays.setAll(a, i -> i * i);         // {0, 1, 4, 9, 16}
Arrays.parallelSetAll(a, i -> i * i); // то же, но в параллель
```

### Преобразование в строку

```java
int[] a = {1, 2, 3};
Arrays.toString(a);      // "[1, 2, 3]"
```

### Мост в коллекции: `asList`

`Arrays.asList` — фиксированная обёртка-список над массивом (не копия!). Менять элементы можно, добавлять/удалять — нельзя (см. [[10. Коллекции и структуры данных#List|List]]):

```java
Integer[] boxed = {1, 2, 3};
List<Integer> list = Arrays.asList(boxed);   // вид на массив
list.set(0, 10);      // ок — отразится на boxed
// list.add(4);       // UnsupportedOperationException

// независимая неизменяемая копия (Java 9+)
List<Integer> copy = List.of(boxed);
```

**Важно**: `asList` не упаковывает примитивы — `Arrays.asList(intArray)` даст `List<int[]>` из одного элемента. Для примитивных массивов нужен ручной цикл или stream (см. [[11. Лямбда-выражения и Stream API#Примитивные потоки|примитивные потоки]]).

Для объектов — сортировка через `Comparable`/`Comparator` (см. [[10. Коллекции и структуры данных#Сортировка|сортировку коллекций]]).

### Поиск

Бинарный поиск по отсортированному массиву; возвращает индекс или отрицательное значение (точка вставки) при отсутствии.

```java
int[] a = {1, 2, 3, 4, 5};
Arrays.binarySearch(a, 3);   // 2
Arrays.binarySearch(a, 9);   // -6 (отсутствует, точка вставки ~ index)

// диапазонный поиск
Arrays.binarySearch(a, 1, 4, 3);   // поиск в [1..4)
```

### Сравнение

```java
int[] a = {1, 2};
int[] b = {1, 2};
Arrays.equals(a, b);        // true — поэлементно
Arrays.compare(a, b);       // 0 — лексикографически (Java 9+)
Arrays.compareUnsigned(a, b); // беззнаковое сравнение (Java 9+)

// многомерные
int[][] deepA = {{1}, {2}};
int[][] deepB = {{1}, {2}};
Arrays.deepEquals(deepA, deepB);  // true — глубокое сравнение
Arrays.deepToString(deepA);       // "[[1], [2]]"
```

### Заполнение и генерация

```java
int[] a = new int[5];
Arrays.fill(a, 42);                    // {42, 42, 42, 42, 42}
Arrays.fill(a, 1, 4, 99);              // {42, 99, 99, 99, 42} — диапазон

// заполнение по формуле (Java 8+)
Arrays.setAll(a, i -> i * i);          // {0, 1, 4, 9, 16}
Arrays.parallelSetAll(a, i -> i * i);  // то же, но в параллель
```

### Преобразование в строку

```java
int[] a = {1, 2, 3};
Arrays.toString(a);           // "[1, 2, 3]"
Arrays.deepToString(deepA);   // для многомерных
```

### Хэш-код

```java
int[] a = {1, 2, 3};
Arrays.hashCode(a);           // хэш поэлементно
Arrays.deepHashCode(deepA);   // для многомерных
```

### Stream из массива (Java 8+)

Преобразует массив в stream для функциональной обработки:

```java
int sum = Arrays.stream(new int[]{1, 2, 3}).sum();       // 6
long count = Arrays.stream(new String[]{"a", "b"}).count(); // 2
Arrays.stream(arr, 1, 4);        // поддиапазон [1..4)
```

### Сравнение файлов через `mismatch` (Java 12+)

```java
int[] a = {1, 2, 3, 4};
int[] b = {1, 2, 0, 4};
Arrays.mismatch(a, b);        // 2 — индекс первого расхождения
Arrays.mismatch(a, b, 0, 3, 0, 3); // с диапазонами
```

### Мост в коллекции: `asList`

`Arrays.asList` — фиксированная обёртка-список над массивом (не копия!). Менять элементы можно, добавлять/удалять — нельзя (см. [[10. Коллекции и структуры данных#List|List]]):

```java
Integer[] boxed = {1, 2, 3};
List<Integer> list = Arrays.asList(boxed);   // вид на массив
list.set(0, 10);      // ок — отразится на boxed
// list.add(4);       // UnsupportedOperationException

// независимая неизменяемая копия (Java 9+)
List<Integer> copy = List.of(boxed);
```

**Важно**: `asList` не упаковывает примитивы — `Arrays.asList(intArray)` даст `List<int[]>` из одного элемента. Для примитивных массивов нужен ручной цикл или stream (см. [[11. Лямбда-выражения и Stream API#Примитивные потоки|примитивные потоки]]).

Для объектов — сортировка через `Comparable`/`Comparator` (см. [[10. Коллекции и структуры данных#Сортировка|сортировку коллекций]]).

### Сравнение

```java
int[] a = {1, 2};
int[] b = {1, 2};
Arrays.equals(a, b);     // true — поэлементно
Arrays.compare(a, b);    // 0 — лексикографически
```

Для многомерных — `deepEquals`, `deepToString`.

### Заполнение

```java
int[] a = new int[5];
Arrays.fill(a, 42);      // {42, 42, 42, 42, 42}
```

### Преобразование в строку

```java
int[] a = {1, 2, 3};
Arrays.toString(a);      // "[1, 2, 3]"
```

## Класс `String`

### Неизменяемость

Объекты `String` неизменяемы: любой «изменяющий» метод возвращает новый объект, исходный не меняется. Потокобезопасны и безопасны для передачи.

```java
String s = "abc";
String t = s.toUpperCase();  // "ABC"
s                            // "abc" — исходный не изменился
```

### String Pool

Строковые литералы и результаты конкатенации констант попадают в пул строк — кэш внутри JVM. Строки из пула переиспользуются (см. [[15. JVM, память и профессиональная разработка#Память JVM|память JVM]]).

```java
String a = "hello";         // в пуле
String b = "hello";         // тот же объект из пула
a == b                      // true (одинаковые литералы)
```

Созданная через `new` строка в пул не попадает автоматически.

### Создание строк

```java
String s1 = "hello";                    // литерал -> пул
String s2 = new String("hello");        // новый объект (обычно не нужно)
String s3 = String.valueOf(42);         // "42"
String s4 = "a" + "b";                  // конкатенация, "ab"
```

Конкатенация через `+` (кроме констант, склеиваемых на этапе компиляции) компилируется в цепочку `StringBuilder.append(...).toString()` — она безопасна и в простых случаях эффективна. Внутри **циклов** всё равно лучше явный `StringBuilder` (см. [[#StringBuilder|StringBuilder]]).

### Сравнение

#### `==`

Сравнивает ссылки — для строк обычно ошибка:

```java
String a = "hello";
String b = new String("hello");
a == b        // false — разные объекты
```

#### `equals`

Сравнивает содержимое — корректный способ:

```java
a.equals(b)   // true
```

#### `equalsIgnoreCase`

Без учёта регистра:

```java
"Hello".equalsIgnoreCase("hello")   // true
```

Идиома: `"literal".equals(value)` — безопасна при `value == null`.

### Получение символов

```java
String s = "Java";
s.charAt(0)    // 'J'
s.length()     // 4
s.codePointAt(0) // 74 (код символа)
```

### Поиск

```java
String s = "Hello, world";
s.indexOf('o')      // 4
s.indexOf("wor")    // 7
s.lastIndexOf('o')  // 8
s.indexOf('x')      // -1 — не найдено
s.indexOf('o', 5)   // 8 — начиная с позиции 5
s.indexOf("wor", 3) // 7 — начиная с позиции 3
```

### Проверка содержимого

```java
s.contains("wor")     // true — проверка наличия подстроки
s.startsWith("He")   // true
s.endsWith("ld")     // true
s.regionMatches(7, "world", 0, 5);  // true — сравнение участка строк
```

### Подстроки

```java
String s = "Hello, world";
s.substring(7)      // "world"
s.substring(0, 5)   // "Hello" (endIndex исключается)
```

### Замена

```java
String s = "a-b-c";
s.replace('-', '_')      // "a_b_c" (по символу)
s.replace("-", ":")      // "a:b:c" (по последовательности)
s.replaceAll("\\d", "#") // регулярное выражение (см. [[13. Дата, время, числа и полезные API#Регулярные выражения|regex]])
s.replaceFirst("\\d", "#") // замена только первого совпадения
```

### Разделение и склейка

```java
String csv = "a,b,c";
String[] parts = csv.split(",");    // {"a", "b", "c"}

String joined = String.join(",", "a", "b", "c"); // "a,b,c"
```

### Изменение регистра

```java
"Java".toUpperCase()    // "JAVA"
"Java".toLowerCase()    // "java"
```

### Удаление пробелов

```java
"  x  ".trim()     // "x" — только до/после
"  x  ".strip()    // "x" — то же для ASCII, корректнее для Unicode
```

`stripLeading`/`stripTrailing` убирают пробелы с одной стороны.

### Форматирование

```java
String s = String.format("%s: %d руб.", "Цена", 100); // "Цена: 100 руб."
String r = "%.2f".formatted(3.14159);                 // "3.14"
```

### Проверки `isEmpty`, `isBlank`, `startsWith`, `endsWith`, `contains`

```java
"".isEmpty()            // true
"  ".isBlank()          // true (только пробельные символы)
"Java".startsWith("Ja") // true
"Java".endsWith("va")   // true
"Hello".contains("ell") // true
```

### Сравнение и сопоставление

```java
"abc".compareTo("abd")   // -1 — лексикографическое сравнение
"abc".compareToIgnoreCase("ABC");   // 0

"abc123".matches("[a-z]+\\d+")   // true — вся строка под regex
"a1b2".replaceAll("\\d", "#")    // "a#b#" — замена по regex
```

`matches` требует соответствия **всей** строки (в отличие от `find` в `Matcher`, см. [[13. Дата, время, числа и полезные API#Регулярные выражения|regex]]).

### Новые методы (Java 11+)

```java
"ab".repeat(3);               // "ababab"
"a\nb\nc".lines().toList();   // ["a", "b", "c"] — строки потока
"  x  ".indent(2);            // "    x  " — сдвиг строк
"  x  ".stripIndent();        // "x" — удаление общего отступа (для текстовых блоков)
```

### `String.valueOf` — перегрузки

Статические методы преобразования разных типов в строку:

```java
String s1 = String.valueOf(42);         // "42"
String s2 = String.valueOf(3.14);       // "3.14"
String s3 = String.valueOf(true);       // "true"
String s4 = String.valueOf('A');        // "A"
String s5 = String.valueOf(new char[]{'a', 'b'}); // "ab"
String s6 = String.valueOf(null);       // "null" — в отличие от String.valueOf(Object)!
```

### `intern`

Помещает строку в пул строк (String Pool) или возвращает существующую из пула:

```java
String a = new String("hello");
String b = a.intern();                  // из пула
a == b                                  // false — a не в пуле, b из пула
```

Полезно для уменьшения числа дубликатов строк при загрузке больших данных — но применять осознанно (пул не очищается GC).

### `transform` (Java 12+)

Применяет функцию к строке как к `this`:

```java
String s = "ab".transform(x -> x + "c")
              .transform(String::toUpperCase); // "ABC"
```

Удобно для цепочек преобразований без создания временных переменных.

### `describeConstable` и `resolveConstantDesc` (Java 12+)

Служебные методы для поддержки константных дескрипторов (см. [[15. JVM, память и профессиональная разработка#Reflection|reflection]]).

## `StringBuilder`

### Назначение и изменяемость

`StringBuilder` — изменяемая последовательность символов. Многократная конкатенация строк в цикле создаёт кучу промежуточных объектов; `StringBuilder` этого избегает.

```java
// плохо: в цикле создаётся много String
String s = "";
for (int i = 0; i < 1000; i++) s += i;

// хорошо
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) sb.append(i);
String result = sb.toString();
```

### `append`, `insert`, `delete`, `replace`, `reverse`, `toString`

```java
StringBuilder sb = new StringBuilder("Java");
sb.append(" 21");          // "Java 21"
sb.insert(4, " SE");       // "Java SE 21"
sb.delete(4, 7);           // "Java21"
sb.replace(0, 4, "JDK");   // "JDK21"
sb.reverse();              // "12KDJ"
String s = sb.toString();  // неизменяемая строка
```

## `StringBuffer`

### Отличия от `StringBuilder`

`StringBuffer` — потокобезопасный аналог `StringBuilder` (методы синхронизированы). API одинаковый.

### Потокобезопасность

`StringBuffer` использует синхронизацию, поэтому медленнее. В однопоточном коде всегда предпочтителен `StringBuilder`; `StringBuffer` оправдан только при разделении между потоками (см. [[14. Многопоточность и конкурентность#Синхронизация|синхронизацию]]).

| | `StringBuilder` | `StringBuffer` |
| --- | --- | --- |
| Потокобезопасность | нет | да (синхронизирован) |
| Скорость | выше | ниже |
| Когда | однопоточный код | разделяемый между потоками |

## Сравнение String, StringBuilder, StringBuffer

| Характеристика | `String` | `StringBuilder` | `StringBuffer` |
| --- | --- | --- | --- |
| Изменяемость | нет | да | да |
| Потокобезопасность | да (иммутабелен) | нет | да |
| Производительность конкатенации | низкая (копии) | высокая | средняя |
| Использование в циклах | непригоден | предпочтителен | редко |
| Когда выбирать | константы, ключи Map, многопоточность | однопоточная сборка строк | многопоточная сборка строк |

Практическое правило: `String` для неизменяемых значений, `StringBuilder` для построения строк в одном потоке, `StringBuffer` — наследие, не используйте без явной необходимости в многопоточности.

## Текстовые блоки

С Java 15 многострочные строки задаются тройными кавычками — без экранирования `\n`.

```java
String json = """
    {
      "name": "Java",
      "version": 21
    }
    """;
```

- Отступы: общий отступ всех строк автоматически убирается (по крайнему левому непустому символу).
- Закрывающие `"""` определяют базовый отступ.
- Служебные пробелы можно управлять: `\` в конце строки убирает перевод строки, `\s` — неразрывный пробел.

```java
String sql = """
    SELECT id, name
    FROM users
    WHERE active = true
    """;
```

Подробнее о работе со строками и производительности — [[10. Коллекции и структуры данных#List|списки]] (как динамическая альтернатива массивам).

## Character и работа с символами

Класс-обёртка `Character` — методы для проверки и преобразования символов:

```java
Character.isDigit('5');          // true
Character.isLetter('A');         // true
Character.isLetterOrDigit('!');  // false
Character.isWhitespace(' ');     // true
Character.isUpperCase('A');      // true
Character.toLowerCase('A');      // 'a'
Character.toUpperCase('a');      // 'A'
Character.isJavaIdentifierStart('_'); // true — может начинать идентификатор
```

**Работа с кодовыми точками Unicode** (для символов вне BMP):

```java
int cp = "😀".codePointAt(0);          // 128512
Character.isSupplementaryCodePoint(cp); // true — суррогатная пара
Character.isSurrogatePair('\uD83D', '\uDE00'); // true

// charCount: сколько char (1 или 2) нужно для кодовой точки
Character.charCount(0x1F600);           // 2
```


### Платформа Java
- **JDK (Java Development Kit)** – набор инструментов для разработки на Java, включает компилятор (javac), стандартные библиотеки, утилиты и JRE.
- **JRE (Java Runtime Environment)** – среда выполнения, необходимая для запуска Java-программ. Содержит JVM и базовые библиотеки классов.
- **JVM (Java Virtual Machine)** – виртуальная машина Java, исполняющая байт-код. Обеспечивает переносимость программ («написано однажды, работает везде»).
- **Байт-код** – промежуточный низкоуровневый код, в который компилируется исходный Java-файл. Выполняется JVM.
- **Компиляция** – процесс преобразования исходного кода (.java) в байт-код (.class) с помощью команды `javac`.
- **Интерпретация** – выполнение байт-кода виртуальной машиной Java (команда `java`).

### Базовые строительные блоки кода
- **Класс** – шаблон или описание объекта, определяющий его поля (данные) и методы (поведение). Вся программа на Java состоит из классов.
- **Объект (экземпляр класса)** – конкретный представитель класса, созданный с помощью оператора `new`. Обладает собственным состоянием, хранящимся в полях.
- **Метод** – блок кода внутри класса, выполняющий определённую задачу. Аналог функции в процедурном программировании.
- **Поле (переменная экземпляра)** – переменная, объявленная внутри класса, но вне методов. Хранит состояние объекта.
- **Локальная переменная** – переменная, объявленная внутри метода или блока кода. Существует только во время выполнения этого блока.
- **Параметр** – переменная, указанная в объявлении метода и принимающая значение при его вызове.
- **Конструктор** – специальный метод, вызываемый при создании объекта. Имя совпадает с именем класса, не имеет возвращаемого типа. Инициализирует новое состояние объекта.
- **Ключевое слово `this`** – ссылка на текущий объект внутри метода или конструктора. Используется для доступа к полям, если их имена перекрыты локальными переменными, или для вызова других конструкторов.
- **Ключевое слово `static`** – обозначает принадлежность классу, а не экземпляру. Статические методы и поля можно использовать без создания объекта.
- **Ключевое слово `final`** – делает сущность неизменяемой: переменную – константой, метод – запрещённым к переопределению, класс – запрещённым к наследованию.
- **Ключевое слово `void`** – указывает, что метод не возвращает никакого значения.
- **Метод `main()`** – точка входа в программу. Сигнатура: `public static void main(String[] args)`. С него начинается выполнение.

### Типы данных и литералы
- **Примитивные типы** – восемь встроенных типов, хранящих простые значения (не объекты): `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`.
- **Ссылочный тип** – тип, хранящий ссылку (адрес) на объект в памяти. Классы, массивы, интерфейсы относятся к ссылочным типам.
- **Литерал** – явное представление значения в коде, например: `42`, `3.14`, `'A'`, `true`, `"Hello"`.
- **Идентификатор** – имя, присвоенное переменной, методу, классу и т.д. Правила: начинается с буквы, `_` или `$`, далее буквы/цифры; чувствителен к регистру.
- **Ключевые слова** – зарезервированные языком слова (`class`, `if`, `new`, `return`, `int` и др.), которые нельзя использовать как идентификаторы.

### Управляющие конструкции
- **Блок кода** – группа операторов, заключённая в фигурные скобки `{}`. Может использоваться везде, где ожидается один оператор.
- **Условный оператор `if`** – выполняет блок кода, если заданное булево условие истинно. Может сопровождаться блоком `else`.
- **Цикл `for`** – компактная форма цикла с инициализацией, условием и итерационным шагом в одной строке.
- **Цикл `while`** – выполняет блок кода, пока условие истинно. Проверка происходит перед каждой итерацией.
- **Цикл `do-while`** – похож на `while`, но условие проверяется после выполнения блока, поэтому тело выполняется хотя бы один раз.

### Объектно-ориентированное программирование
- **Инкапсуляция** – объединение данных и методов в классе и сокрытие внутреннего состояния от прямого внешнего вмешательства. Реализуется модификаторами доступа и геттерами/сеттерами.
- **Наследование (`extends`)** – механизм создания класса на основе другого. Дочерний класс получает (наследует) поля и методы родителя, может добавлять свои или переопределять существующие.
- **Полиморфизм** – способность объектов разных типов обрабатывать вызов одного и того же метода по-разному. Достигается переопределением методов (динамический полиморфизм) и перегрузкой (статический полиморфизм).
- **Переопределение метода (override)** – объявление в подклассе метода с точно такой же сигнатурой, как в родительском классе. Вызов переопределённого метода для объекта подкласса исполняет новую версию.
- **Перегрузка метода (overload)** – создание методов с одинаковым именем, но разными параметрами (количество, тип, порядок). Позволяет выполнять похожие действия с разными входными данными.
- **Абстрактный класс** – класс, который нельзя инстанциировать (создать объект). Может содержать как обычные методы, так и абстрактные (без реализации). Используется как основа для иерархии.
- **Интерфейс (`interface`)** – набор абстрактных методов (и, начиная с Java 8, методов с реализацией по умолчанию). Класс, реализующий интерфейс, обязуется предоставить реализацию всех его абстрактных методов.
- **Модификаторы доступа** – ключевые слова, управляющие видимостью классов, полей и методов: `public` (доступен везде), `protected` (внутри пакета и в подклассах), default (без слова, только внутри пакета), `private` (только в своём классе).

### Работа с программой и библиотеками
- **Пакет (`package`)** – способ логической группировки родственных классов и интерфейсов. Помогает избежать конфликтов имён и структурировать проект.
- **Импорт (`import`)** – инструкция, позволяющая использовать короткое имя класса из другого пакета вместо полного (например, `java.util.Scanner`).
- **Стандартная библиотека** – обширный набор готовых классов и интерфейсов, входящих в JDK. Наиболее важные пакеты: `java.lang`, `java.util`, `java.io`, `java.net`.
- **`System.out.println()`** – стандартный способ вывода текста в консоль. `System` – класс из пакета `java.lang`, `out` – статическое поле (объект PrintStream), `println()` – метод этого объекта.

### Дополнительно (встречается по мере обучения)
- **Массив** – структура данных, хранящая фиксированное количество элементов одного типа. Создаётся с помощью оператора `new`, например: `int[] arr = new int[10];`.
- **Исключение (Exception)** – событие, возникающее при ошибке во время выполнения программы. Механизм обработки: блоки `try`, `catch`, `finally`.
- **Коллекции** – динамические структуры данных в `java.util`. Основные: `ArrayList` (список на основе массива), `HashMap` (хранение пар «ключ-значение»).
- **Обобщения (Generics)** – синтаксическая конструкция, позволяющая создавать классы и методы, работающие с разными типами, сохраняя безопасность типов. Пример: `ArrayList<String>`.
- **Лямбда-выражение** – краткий способ записи анонимной функции. Используется в основном для реализации функциональных интерфейсов. Синтаксис: `(параметры) -> выражение`.
- **Аннотация** – форма метаданных, добавляемая в код и не влияющая напрямую на выполнение. Часто используется компилятором и инструментами (например, `@Override`, `@Deprecated`).

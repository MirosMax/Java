# База знаний по Java для Obsidian

Энциклопедический справочник по языку Java для разработчика с базовыми знаниями программирования. Ориентир — **Java 21 (LTS)**.

| `02. Операторы и управление потоком.md` | Операторы, `switch`, циклы, переходы |

## Как устроена заметка

- Ручное оглавление из вики-ссылок `[[#Заголовок|Заголовок]]`.
- Заголовки без номеров, глубина до 3–4 уровней.
- Короткие примеры кода (5–15 строк), таблицы сравнений, диаграммы Mermaid.
- Перекрёстные вики-ссылки между заметками.

## Порядок работы

1. Структура утверждена (см. `План.md` и `AGENTS.md`).
2. Заметки генерируются **по одной** в нумерационном порядке.
3. После каждой заметки — коммит (пушит пользователь).
4. Глоссарий `0. Термины и определения.md` дополняется по мере появления новых терминов.

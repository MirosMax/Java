## Объявление методов

Общая форма:

```java
модификаторы типВозврата имя(параметры) {
    // тело
}
```

Пример:

```java
public int add(int a, int b) {
    return a + b;
}
```

### Тип возвращаемого значения

- Примитив, ссылочный тип или `void` (ничего не возвращает).
- `void`-метод может содержать `return;` для раннего выхода.

### Имя

- Идентификатор по правилам именования (см. [[01. Основы языка Java#Идентификаторы и ключевые слова|идентификаторы]]).
- Соглашение — lowerCamelCase: `getTotal`, `printReport`.

### Параметры

Список переменных, принимаемых методом: `тип имя`. Параметры — это локальные переменные метода.

### Тело метода и `return`

`return` завершает метод и возвращает значение. Для не-`void` методов обязательно наличие `return` на всех путях выполнения.

```java
int max(int a, int b) {
    if (a > b) return a;
    return b;
}
```

## Параметры и аргументы

**Параметр** — переменная в объявлении. **Аргумент** — фактическое значение при вызове.

### Примитивные аргументы

Передаётся копия значения — изменение параметра не влияет на вызывающий код.

```java
void inc(int x) { x++; }

int v = 5;
inc(v);
// v == 5 — не изменилось
```

### Ссылочные аргументы

Передаётся копия ссылки на тот же объект.

### Передача по значению

Java всегда передаёт параметры **по значению**: для примитивов — значение, для ссылочных типов — значение ссылки (адрес объекта). Сам объект не копируется.

```java
void change(StringBuilder sb) {
    sb.append("!");        // меняет объект — видно снаружи
    sb = new StringBuilder("new"); // переприсваивание — НЕ видно снаружи
}

StringBuilder b = new StringBuilder("hi");
change(b);
// b == "hi!"
```

### Изменение объектов внутри метода

Изменение состояния переданного объекта видно вызывающему коду (через ссылку), а переприсваивание параметра — нет.

## Возвращение значений

### Примитивы, объекты, массивы, `null`

```java
int answer() { return 42; }
String name() { return "Java"; }
int[] data() { return new int[]{1, 2}; }
String maybe() { return null; }   // ссылочный тип может вернуть null
```

При возврате ссылочного типа возвращается ссылка, объект не копируется.

## Перегрузка методов

Методы с одинаковым именем, но разными сигнатурами (параметрами). Позволяет одинаково называть похожие операции.

### Разные количества параметров

```java
int sum(int a, int b) { return a + b; }
int sum(int a, int b, int c) { return a + b + c; }
```

### Разные типы параметров

```java
double convert(double v) { return v; }
String convert(String s) { return s; }
```

### Разный порядок типов

```java
void log(String msg, int level) { }
void log(int level, String msg) { }
```

Сигнатуру определяют типы и их порядок, **не** имена параметров и не тип возврата.

### Выбор перегруженного метода

Компилятор выбирает наиболее точное соответствие аргументов.

### Автоматические преобразования

Если точного совпадения нет, подбирается метод через неявное расширение типов (см. [[01. Основы языка Java#Неявное расширение|расширение типов]]).

```java
void print(int x) { }
print(42L);   // ошибка: long не сужается автоматически
print(42);    // ок
```

### Неоднозначность

Если аргумент подходит двум методам одинаково, компилятор выдаёт ошибку.

```java
void f(int a, double b) { }
void f(double a, int b) { }
// f(1, 1);  // ошибка: неоднозначный вызов
```

## Аргументы переменной длины

### Синтаксис и использование

Varargs позволяют передавать произвольное число аргументов одного типа. Синтаксис — три точки.

```java
int sum(int... values) {
    int s = 0;
    for (int v : values) s += v;
    return s;
}

sum()            // 0
sum(1)           // 1
sum(1, 2, 3)     // 6
```

### Varargs как массив

Внутри метода varargs — это массив. Вызов с массивом тоже допустим.

```java
int[] arr = {1, 2, 3};
sum(arr);    // 6
```

### Ограничения

Varargs-параметр должен быть последним; в методе — только один.

```java
void f(String prefix, int... values) { }   // ок
// void g(int... a, String s) { }          // ошибка: не последний
```

### Перегрузка и неоднозначность

Перегрузка с varargs может быть неоднозначной:

```java
void p(int... a) { }
void p(int a, int... b) { }
// p(1); // ошибка: обе подходят
```

## Рекурсия

Метод, вызывающий сам себя. Решает задачи с самоподобной структурой (обход деревьев, факториал, Фибоначчи).

### Базовый случай

Условие остановки — без него рекурсия бесконечна.

### Рекурсивный вызов

Вызов с аргументами, приближающими к базовому случаю.

```java
int factorial(int n) {
    if (n <= 1) return 1;      // базовый случай
    return n * factorial(n - 1); // рекурсивный вызов
}
```

### Стек вызовов

Каждый вызов кладёт кадр в стек (см. [[15. JVM, память и профессиональная разработка#Память JVM|стек JVM]]): локальные переменные и адрес возврата. Глубина рекурсии ограничена размером стека.

### Рекурсия против итерации

| | Рекурсия | Итерация |
| --- | --- | --- |
| Читаемость | лучше для деревьев/вложенности | лучше для простых циклов |
| Память | расходует стек | константная |
| Риски | `StackOverflowError` при большой глубине | нет |

### `StackOverflowError`

При слишком глубокой рекурсии переполняется стек — выбрасывается `StackOverflowError` (это `Error`, см. [[08. Исключения и обработка ошибок#Иерархия исключений|иерархию исключений]]).

```java
// бесконечная рекурсия -> StackOverflowError
int infinite(int n) { return infinite(n + 1); }
```

## Статические методы

Принадлежат классу, а не экземпляру. Вызываются через имя класса (см. [[05. Классы и объекты#Ключевое слово static|static]]).

### Доступ к статическим членам

```java
class MathUtils {
    static int square(int x) { return x * x; }
}

int s = MathUtils.square(5);   // 25
```

### Ограничения статического контекста

Статический метод не может обращаться к нестатическим полям/методам (у него нет экземпляра) и не может использовать `this`.

```java
class Demo {
    int value;
    static void bad() {
        // value = 5;   // ошибка: нет экземпляра
        // this.value;  // ошибка: this недоступен
    }
}
```

### `this` и `static`

`this` — ссылка на текущий экземпляр; в статическом контексте её нет. Статические методы вызываются без объекта.

## Аргументы командной строки

### `String[] args`

Метод `main` принимает аргументы командной строки как массив строк (см. [[01. Основы языка Java#Метод main|метод main]]).

```text
java App alpha 42
```

### Разбор и проверка количества

```java
public static void main(String[] args) {
    if (args.length < 2) {
        System.out.println("Использование: App <имя> <возраст>");
        return;
    }
    String name = args[0];
    int age = Integer.parseInt(args[1]);
    System.out.println(name + ": " + age);
}
```

### Преобразование строк в числа

Парсинг через wrapper-классы (см. [[13. Дата, время, числа и полезные API#Парсинг чисел|парсинг чисел]]); некорректное число бросает `NumberFormatException`.

```java
int n = Integer.parseInt("42");
double d = Double.parseDouble("3.14");
long l = Long.parseLong("1234567890");
```

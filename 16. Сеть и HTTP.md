## Сетевые адреса

### `InetAddress`

Абстракция IP-адреса (`java.net`). Создаётся фабричными методами, прямого конструктора нет:

```java
InetAddress addr = InetAddress.getByName("example.com");   // по имени
InetAddress ip = InetAddress.getByName("93.184.216.34");   // по IP
InetAddress local = InetAddress.getLocalHost();            // локальный

addr.getHostName();   // "example.com"
addr.getHostAddress();// "93.184.216.34"
addr.isReachable(3000); // проверка доступности (3 c)
```

`Inet4Address`/`Inet6Address` — подтипы для IPv4/IPv6. Имя может разрешаться в несколько адресов:

```java
InetAddress[] all = InetAddress.getAllByName("example.com");
```

## TCP-сокеты

Установленное соединение: клиент `Socket`, сервер `ServerSocket`.

### Клиент

```java
try (Socket socket = new Socket("example.com", 80);
     var out = new PrintWriter(socket.getOutputStream(), true);
     var in = new BufferedReader(new InputStreamReader(socket.getInputStream()))) {

    out.println("GET / HTTP/1.1\r\nHost: example.com\r\n\r\n");
    in.lines().limit(5).forEach(System.out::println);
}
```

### Сервер

```java
try (ServerSocket server = new ServerSocket(8080)) {
    System.out.println("Слушаем 8080...");
    while (true) {
        try (Socket client = server.accept()) {   // блокирует до подключения
            // обработать клиента
        }
    }
}
```

Для многоклиентского сервера — поток на соединение (см. [[14. Многопоточность и конкурентность|многопоточность]]); для массовых соединений — virtual threads (см. [[14. Многопоточность и конкурентность#Virtual threads|virtual threads]]).

### Таймауты

```java
Socket socket = new Socket();
socket.connect(new InetSocketAddress("example.com", 80), 3000);  // таймаут 3 c
socket.setSoTimeout(2000);   // таймаут чтения
```

## URL и URI

`URL` — адрес ресурса с возможностью открыть соединение; `URI` — синтаксическая абстракция (без сетевой семантики).

```java
URL url = new URL("https://example.com/path?q=java");
url.getProtocol();   // "https"
url.getHost();       // "example.com"
url.getPath();       // "/path"
url.getQuery();      // "q=java"

URI uri = url.toURI();
```

`URL` сравнивается по адресу (и резолвит DNS), `URI` — по синтаксису. Для парсинга адресов предпочтителен `URI`.

## HttpURLConnection

Классический синхронный HTTP (устаревающий — вместо него `HttpClient`, см. [[#HttpClient|HttpClient]]):

```java
HttpURLConnection conn = (HttpURLConnection) new URL("https://api.example.com/data").openConnection();
conn.setRequestMethod("GET");
conn.setRequestProperty("Accept", "application/json");

int code = conn.getResponseCode();              // 200, 404...
var in = new BufferedReader(new InputStreamReader(conn.getInputStream()));
String body = in.lines().collect(Collectors.joining("\n"));
conn.disconnect();
```

## HttpClient

Современный HTTP-клиент (`java.net.http`, Java 11+) — синхронный и асинхронный, HTTP/2, WebSocket.

### Создание клиента и запрос

```java
HttpClient client = HttpClient.newBuilder()
        .connectTimeout(Duration.ofSeconds(5))
        .build();

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://api.example.com/data"))
        .timeout(Duration.ofSeconds(10))
        .header("Accept", "application/json")
        .GET()
        .build();
```

### Синхронный запрос

```java
HttpResponse<String> response =
        client.send(request, HttpResponse.BodyHandlers.ofString());

response.statusCode();   // 200
response.body();         // строка ответа
```

### Асинхронный запрос

Возвращает `CompletableFuture` (см. [[14. Многопоточность и конкурентность#CompletableFuture|CompletableFuture]]):

```java
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
      .thenAccept(resp -> System.out.println(resp.body()));
```

### Тело запроса и методы

```java
HttpRequest post = HttpRequest.newBuilder()
        .uri(URI.create("https://api.example.com/items"))
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"name\":\"A\"}"))
        .build();
```

`BodyPublishers`/`BodyHandlers`: `ofString`, `ofByteArray`, `ofInputStream`, `ofFile(Path)`, `ofLines`.

### WebSocket (Java 11+)

```java
WebSocket ws = HttpClient.newHttpClient()
        .newWebSocketBuilder()
        .buildAsync(URI.create("wss://echo.example.com"), new WebSocket.Listener() {
            public void onOpen(WebSocket webSocket) {
                webSocket.sendText("привет", true);
            }
        })
        .join();
```

## UDP-дейтаграммы

Без установления соединения: `DatagramSocket` + `DatagramPacket`.

```java
// отправитель
byte[] data = "ping".getBytes();
DatagramPacket packet = new DatagramPacket(data, data.length,
        InetAddress.getByName("127.0.0.1"), 4445);
try (DatagramSocket socket = new DatagramSocket()) {
    socket.send(packet);
}

// получатель
byte[] buf = new byte[1024];
DatagramPacket incoming = new DatagramPacket(buf, buf.length);
try (DatagramSocket socket = new DatagramSocket(4445)) {
    socket.receive(incoming);        // блокирует до пакета
    String msg = new String(incoming.getData(), 0, incoming.getLength());
}
```

UDP — быстрее, без гарантий доставки/порядка; для надёжности — TCP.

## Сетевые исключения

- `UnknownHostException` — не удалось разрешить имя.
- `ConnectException` — соединение отклонено.
- `SocketTimeoutException` — истёк таймаут (подкласс `IOException`).
- `BindException` — порт занят.
- `IOException` — базовая ошибка ввода-вывода/сети (см. [[08. Исключения и обработка ошибок#Checked exceptions|checked exceptions]]).

Типовая обработка — `try`-with-resources + catch `IOException` (см. [[12. Ввод-вывод, файлы и сериализация|ввод-вывод]]).

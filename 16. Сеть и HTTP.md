## Сетевые адреса

### `InetAddress`

Абстракция IP-адреса (`java.net`). Создаётся фабричными методами, прямого конструктора нет:

```java
InetAddress addr = InetAddress.getByName("example.com");   // по имени
InetAddress ip = InetAddress.getByName("93.184.216.34");   // по IP
InetAddress local = InetAddress.getLocalHost();            // локальный

addr.getHostName();   // "example.com"
addr.getHostAddress();// "93.184.216.34"
addr.isReachable(3000); // проверка доступности (3 c)
```

`Inet4Address`/`Inet6Address` — подтипы для IPv4/IPv6. Имя может разрешаться в несколько адресов:

```java
InetAddress[] all = InetAddress.getAllByName("example.com");
```

Проверки типа адреса и сетевые интерфейсы:

```java
ip.isLoopbackAddress();     // 127.0.0.1
ip.isSiteLocalAddress();    // приватный диапазон (10.x, 192.168.x)
ip.isMulticastAddress();    // multicast-адрес

// сетевые интерфейсы машины
NetworkInterface ni = NetworkInterface.getByInetAddress(ip);
ni.getName();               // "eth0"
ni.getDisplayName();
ni.getHardwareAddress();    // MAC-адрес
NetworkInterface.getNetworkInterfaces();   // все интерфейсы
```

## TCP-сокеты

Установленное соединение: клиент `Socket`, сервер `ServerSocket`.

### Клиент

```java
try (Socket socket = new Socket("example.com", 80);
     var out = new PrintWriter(socket.getOutputStream(), true);
     var in = new BufferedReader(new InputStreamReader(socket.getInputStream()))) {

    out.println("GET / HTTP/1.1\r\nHost: example.com\r\n\r\n");
    in.lines().limit(5).forEach(System.out::println);
}
```

### Сервер

```java
try (ServerSocket server = new ServerSocket(8080)) {
    System.out.println("Слушаем 8080...");
    while (true) {
        try (Socket client = server.accept()) {   // блокирует до подключения
            // обработать клиента
        }
    }
}
```

Параметры сервера и клиентской стороны:

```java
// сервер
server.setSoTimeout(10_000);     // таймаут accept()
server.getLocalPort();           // порт, если 0 (автовыбор)

// на клиентском сокете
socket.getInetAddress();         // удалённый адрес
socket.getPort();                // удалённый порт
socket.getLocalPort();           // локальный порт
socket.setTcpNoDelay(true);      // отключить алгоритм Нейгла
socket.setKeepAlive(true);       // keep-alive
```

Для многоклиентского сервера — поток на соединение (см. [[14. Многопоточность и конкурентность|многопоточность]]); для массовых соединений — virtual threads (см. [[14. Многопоточность и конкурентность#Virtual threads|virtual threads]]).

### Чтение и запись

Байтовый обмен и символьный — по аналогии с I/O (см. [[12. Ввод-вывод, файлы и сериализация|ввод-вывод]]):

```java
// байтовый
try (var out = socket.getOutputStream(); var in = socket.getInputStream()) {
    out.write(new byte[]{1, 2, 3});
    out.flush();
    int b = in.read();
}
```

### Таймауты

```java
Socket socket = new Socket();
socket.connect(new InetSocketAddress("example.com", 80), 3000);  // таймаут 3 c
socket.setSoTimeout(2000);   // таймаут чтения
```

## URL и URI

`URL` — адрес ресурса с возможностью открыть соединение; `URI` — синтаксическая абстракция (без сетевой семантики).

```java
URL url = new URL("https://example.com/path?q=java");
url.getProtocol();   // "https"
url.getHost();       // "example.com"
url.getPath();       // "/path"
url.getQuery();      // "q=java"

URI uri = url.toURI();
```

`URL` сравнивается по адресу (и резолвит DNS), `URI` — по синтаксису. Для парсинга адресов предпочтителен `URI`.

### Построение и разбор `URI`

```java
URI uri = new URI("https", "example.com", "/path", "q=java", null);
// scheme, host, path, query, fragment

// относительные и абсолютные
URI base = URI.create("https://example.com/api");
URI rel = base.resolve("users/1");          // https://example.com/api/users/1
URI back = base.relativize(rel);            // "users/1"

// разбор компонентов
uri.getScheme();    // "https"
uri.getAuthority(); // "example.com"
uri.getRawPath();   // "/path" без декодирования
```

### Кодирование URL-компонентов

```java
URLEncoder.encode("а бв", StandardCharsets.UTF_8);   // "а+%D0%B1%D0%B2"
URLDecoder.decode("%D0%B0", StandardCharsets.UTF_8); // "а"

// для query-параметра лучше, чем URLEncoder:
URI.create("https://x.com/search?q=" + URLEncoder.encode("java 21", StandardCharsets.UTF_8));
```

## HttpURLConnection

Классический синхронный HTTP (устаревающий — вместо него `HttpClient`, см. [[#HttpClient|HttpClient]]):

```java
HttpURLConnection conn = (HttpURLConnection) new URL("https://api.example.com/data").openConnection();
conn.setRequestMethod("GET");
conn.setRequestProperty("Accept", "application/json");

int code = conn.getResponseCode();              // 200, 404...
var in = new BufferedReader(new InputStreamReader(conn.getInputStream()));
String body = in.lines().collect(Collectors.joining("\n"));
conn.disconnect();
```

Настройки и POST:

```java
conn.setConnectTimeout(3000);          // таймаут соединения
conn.setReadTimeout(3000);             // таймаут чтения
conn.setRequestProperty("User-Agent", "demo");

conn.setRequestMethod("POST");
conn.setDoOutput(true);                // разрешить запись тела
conn.setRequestProperty("Content-Type", "application/json");
try (var out = conn.getOutputStream()) {
    out.write("{\"name\":\"A\"}".getBytes(StandardCharsets.UTF_8));
}

// чтение ошибки (код >= 400): тело в getErrorStream()
if (code >= 400) {
    var err = new BufferedReader(new InputStreamReader(conn.getErrorStream()));
    // ...
}
```

**Подводный камень**: после `connect()` нельзя менять метод и заголовки. HTTP-методы «нестандартные» (PATCH и др.) могут отклоняться — требуют `setRequestMethod` со спец-разрешённым списком.

## HttpClient

Современный HTTP-клиент (`java.net.http`, Java 11+) — синхронный и асинхронный, HTTP/2, WebSocket.

### Создание клиента и запрос

```java
HttpClient client = HttpClient.newBuilder()
        .connectTimeout(Duration.ofSeconds(5))
        .build();

HttpRequest request = HttpRequest.newBuilder()
        .uri(URI.create("https://api.example.com/data"))
        .timeout(Duration.ofSeconds(10))
        .header("Accept", "application/json")
        .GET()
        .build();
```

Настройки клиента: версия HTTP, перенаправления, аутентификация:

```java
HttpClient client = HttpClient.newBuilder()
        .version(HttpClient.Version.HTTP_2)          // HTTP/2 (с фолбэком на 1.1)
        .followRedirects(HttpClient.Redirect.NORMAL) // авто-редиректы
        .authenticator(new Authenticator() {         // Basic-аутентификация
            protected PasswordAuthentication getPasswordAuthentication() {
                return new PasswordAuthentication("user", "pass".toCharArray());
            }
        })
        .cookieHandler(new CookieManager())          // управление cookies
        .proxy(ProxySelector.of(new InetSocketAddress("proxy", 8080)))
        .executor(Executors.newFixedThreadPool(4))   // пул для async
        .build();
```

### Синхронный запрос

```java
HttpResponse<String> response =
        client.send(request, HttpResponse.BodyHandlers.ofString());

response.statusCode();   // 200
response.body();         // строка ответа
```

### Асинхронный запрос

Возвращает `CompletableFuture` (см. [[14. Многопоточность и конкурентность#CompletableFuture|CompletableFuture]]):

```java
client.sendAsync(request, HttpResponse.BodyHandlers.ofString())
      .thenAccept(resp -> System.out.println(resp.body()));
```

### Ответ `HttpResponse`

```java
HttpResponse<String> resp = client.send(request, BodyHandlers.ofString());

resp.statusCode();                // 200
resp.body();                      // тело
resp.headers();                   // HttpHeaders
resp.headers().firstValue("Content-Type");  // "application/json"
resp.request().uri();             // исходный запрос
resp.version();                   // HTTP_1_1 / HTTP_2
resp.uri();                       // финальный URI (после редиректов)
```

### BodyHandlers и BodyPublishers

```java
BodyHandlers.ofString();            // строка
BodyHandlers.ofByteArray();         // byte[]
BodyHandlers.ofInputStream();       // InputStream (большие ответы)
BodyHandlers.ofFile(Path.of("out.json"));   // в файл
BodyHandlers.discarding();          // игнорировать тело

BodyPublishers.ofString(json);      // из строки
BodyPublishers.ofByteArray(bytes);  // из байтов
BodyPublishers.ofFile(path);        // из файла
BodyPublishers.noBody();            // пустое тело
```

### GET с параметрами

```java
URI uri = URI.create("https://api.example.com/search?q="
        + URLEncoder.encode("java 21", StandardCharsets.UTF_8)
        + "&limit=10");

HttpRequest get = HttpRequest.newBuilder(uri)
        .header("Accept", "application/json")
        .GET()
        .build();
```

### Обработка ошибок

```java
// не-2xx код — не исключение, проверяйте statusCode()
if (resp.statusCode() >= 400) { ... }

// сетевые ошибки
try {
    client.send(request, BodyHandlers.ofString());
} catch (IOException | InterruptedException e) {
    // соединение, таймаут, прерывание (см. [[08. Исключения и обработка ошибок|исключения]])
}

// асинхронный вариант
client.sendAsync(request, BodyHandlers.ofString())
      .handle((r, ex) -> ex != null ? fallback(r, ex) : r);
```

### Тело запроса и методы

```java
HttpRequest post = HttpRequest.newBuilder()
        .uri(URI.create("https://api.example.com/items"))
        .header("Content-Type", "application/json")
        .POST(HttpRequest.BodyPublishers.ofString("{\"name\":\"A\"}"))
        .build();
```

`BodyPublishers`/`BodyHandlers`: `ofString`, `ofByteArray`, `ofInputStream`, `ofFile(Path)`, `ofLines`.

### WebSocket (Java 11+)

```java
WebSocket ws = HttpClient.newHttpClient()
        .newWebSocketBuilder()
        .buildAsync(URI.create("wss://echo.example.com"), new WebSocket.Listener() {
            public void onOpen(WebSocket webSocket) {
                webSocket.sendText("привет", true);
            }
        })
        .join();
```

Методы `WebSocket.Listener` — колбэки асинхронных событий:

```java
new WebSocket.Listener() {
    public void onOpen(WebSocket ws) { }                     // соединение открыто
    public CompletionStage<?> onText(WebSocket ws, CharSequence data, boolean last) {
        System.out.println(data);                            // входящий текст
        return null;
    }
    public void onError(WebSocket ws, Throwable error) { }   // ошибка
    public CompletionStage<?> onClose(WebSocket ws, int code, String reason) { ... }
}
```

`CompletableFuture<WebSocket>` возвращается из `buildAsync`; асинхронная природа требует управления через `CompletionStage` (см. [[14. Многопоточность и конкурентность#CompletableFuture|CompletableFuture]]).

## UDP-дейтаграммы

Без установления соединения: `DatagramSocket` + `DatagramPacket`.

```java
// отправитель
byte[] data = "ping".getBytes();
DatagramPacket packet = new DatagramPacket(data, data.length,
        InetAddress.getByName("127.0.0.1"), 4445);
try (DatagramSocket socket = new DatagramSocket()) {
    socket.send(packet);
}

// получатель
byte[] buf = new byte[1024];
DatagramPacket incoming = new DatagramPacket(buf, buf.length);
try (DatagramSocket socket = new DatagramSocket(4445)) {
    socket.receive(incoming);        // блокирует до пакета
    String msg = new String(incoming.getData(), 0, incoming.getLength());
}
```

UDP — быстрее, без гарантий доставки/порядка; для надёжности — TCP.

### Multicast (групповая рассылка)

```java
// подписчик группы
MulticastSocket ms = new MulticastSocket(4446);
InetAddress group = InetAddress.getByName("230.0.0.1");
ms.joinGroup(group);                    // войти в группу
byte[] buf = new byte[1024];
DatagramPacket p = new DatagramPacket(buf, buf.length);
ms.receive(p);                          // получить пакет от любого участника
// ms.leaveGroup(group);

// отправитель в группу
try (MulticastSocket sender = new MulticastSocket()) {
    DatagramPacket packet = new DatagramPacket(data, data.length, group, 4446);
    sender.send(packet);
}
```

Multicast использует адреса `224.0.0.0/4` (IPv4). Применение: обнаружение сервисов, рассылка уведомлений в локальной сети.

## Сетевые исключения

- `UnknownHostException` — не удалось разрешить имя.
- `ConnectException` — соединение отклонено.
- `SocketTimeoutException` — истёк таймаут (подкласс `IOException`).
- `BindException` — порт занят.
- `IOException` — базовая ошибка ввода-вывода/сети (см. [[08. Исключения и обработка ошибок#Checked exceptions|checked exceptions]]).

Типовая обработка — `try`-with-resources + catch `IOException` (см. [[12. Ввод-вывод, файлы и сериализация|ввод-вывод]]).

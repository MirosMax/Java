## Арифметические операторы

Работают с примитивными числовыми типами и их обёртками.

### Сложение `+`

```java
int a = 5 + 3; // 8
```

Для `String` оператор `+` выполняет конкатенацию (см. [[03. Массивы и строки#Класс String|String]]). Если один из операндов — строка, остальные приводятся к строке:

```java
String s = "Результат: " + (5 + 3); // "Результат: 8"
String t = "x" + 5 + 3;             // "x53" — левая ассоциативность
```

### Вычитание `-`

```java
int d = 10 - 4; // 6
```

### Умножение `*`

```java
int p = 6 * 7; // 42
```

### Деление `/`

Для целых — целочисленное деление с отбрасыванием дробной части. Для вещественных — обычное.

```java
int a = 7 / 2;   // 3 (не 3.5)
double b = 7.0 / 2; // 3.5
int c = 7 / 0;    // ArithmeticException
double d = 7.0 / 0; // Infinity (для double деление на ноль не бросает)
```

### Остаток от деления `%`

Знак результата совпадает со знаком делимого.

```java
10 % 3 == 1
-10 % 3 == -1
10 % -3 == 1
```

Применение — проверка чётности: `n % 2 == 0`.

### Унарные плюс и минус

```java
int a = -5;
int b = +a;  // -5 (унарный плюс обычно не нужен)
int c = -a;  // 5
```

## Инкремент и декремент

### Префиксная форма `++x`, `--x`

Сначала изменяет, потом возвращает новое значение.

```java
int x = 5;
int y = ++x; // x == 6, y == 6
```

### Постфиксная форма `x++`, `x--`

Возвращает старое значение, потом изменяет.

```java
int x = 5;
int y = x++; // x == 6, y == 5
```

Подводный камень: не использовать в сложных выражениях — легко ошибиться.

```java
int i = 1;
int r = i++ + ++i; // 1 + 3 = 4 — читаемость страдает, избегать
```

## Операторы присваивания

### Простое присваивание `=`

Присваивает правый операнд левому. Левый операнд должен быть переменной (или элементом массива, полем).

```java
int x;
x = 10;
```

Ссылочные типы — присваивание ссылки, а не копии объекта (см. [[05. Классы и объекты#Ссылки на объекты|ссылки на объекты]]):

```java
String a = "hello";
String b = a; // a и b ссылаются на один объект
```

### Составные операторы `+= -= *= /= %=`

Сокращение `x = x op y`. Важно: составной оператор неявно приводит результат к типу переменной.

```java
int x = 5;
x += 3;  // x == 8
x -= 2;  // x == 6
x *= 2;  // x == 12
x /= 4;  // x == 3
x %= 2;  // x == 1
```

Пример неявного приведения:

```java
byte b = 5;
b += 200;  // ок: b == -51 (неявное (byte))
// b = b + 200; // ошибка: b + 200 имеет тип int
```

## Операторы сравнения

Возвращают `boolean`.

### `==` и `!=`

```java
int a = 5, b = 5;
a == b // true
a != b // false
```

Для ссылочных типов `==` сравнивает **ссылки**, а не содержимое. Для строк сравнивать надо `equals` (см. [[03. Массивы и строки#Сравнение|сравнение строк]]).

```java
String s1 = new String("x");
String s2 = new String("x");
s1 == s2        // false — разные объекты
s1.equals(s2)   // true — одинаковое содержимое
```

### `<`, `>`, `<=`, `>=`

Работают с числовыми типами и `char`.

```java
3 < 5    // true
'B' > 'A' // true (66 > 65)
```

## Логические операторы

### `&&` и `||`

Логические И и ИЛИ над `boolean`.

```java
boolean a = true, b = false;
a && b // false
a || b // true
```

### `!`

Логическое НЕ.

```java
!true  // false
!false // true
```

### Короткое замыкание

`&&` и `||` вычисляют правый операнд только если результат ещё не определён. Это даёт безопасную проверку:

```java
if (list != null && !list.isEmpty()) {   // вторая часть не вызовется при null
    // безопасно
}

if (x == 0 || 10 / x > 1) {   // нет деления на ноль при x == 0
    // ...
}
```

Различие с побитовыми `&` и `|`: те вычисляют оба операнда всегда.

## Побитовые операторы

Работают с целыми типами по битам (см. [[#Битовые маски|битовые маски]]).

### `&`

Побитовое И: 1 только если оба бита 1.

```java
0b1100 & 0b1010 // 0b1000 (8)
```

### `|`

Побитовое ИЛИ: 1 если хотя бы один бит 1.

```java
0b1100 | 0b0011 // 0b1111 (15)
```

### `^`

Побитовое исключающее ИЛИ (XOR): 1 если биты различаются.

```java
0b1100 ^ 0b1010 // 0b0110 (6)
```

### `~`

Побитовое НЕ (инверсия всех битов). Однооператорный.

```java
~5 // -6 (инверсия всех битов int)
```

### Сдвиги

#### `<<`

Сдвиг влево: биты смещаются влево, справа дополняются нулями. Эквивалент умножения на степень двойки.

```java
5 << 2 // 20 (5 * 2²)
```

#### `>>`

Сдвиг вправо со знаком: слева дополняется знаковым битом. Эквивалент деления на степень двойки.

```java
-16 >> 2 // -4 (знак сохраняется)
```

#### `>>>`

Беззнаковый сдвиг вправо: слева всегда нули.

```java
-1 >>> 1 // 2147483647 (биты сдвинуты, старший стал 0)
```

### Битовые маски

Типовой приём — флаги в одном `int`.

```java
int READ = 1 << 0;   // 0001
int WRITE = 1 << 1;  // 0010
int EXEC = 1 << 2;   // 0100

int perms = READ | WRITE;      // 0011 — включить
boolean canRead = (perms & READ) != 0; // true
boolean canExec = (perms & EXEC) != 0; // false
perms &= ~WRITE;               // выключить бит WRITE
```

## Тернарный оператор

### Синтаксис `? :`

```java
int max = a > b ? a : b;  // если условие истинно — a, иначе b
```

Заменяет короткий `if-else`, возвращающий значение.

### Вложенные тернарные выражения

```java
String grade = score >= 90 ? "A"
              : score >= 75 ? "B"
              : score >= 60 ? "C"
              : "F";
```

Ассоциативность тернарного оператора — правая, поэтому вложенность работает. При сложных условиях читаемость лучше у `if-else` или `switch`.

### Выведение результирующего типа

Тип результата — общий тип двух ветвей по правилам числового продвижения:

```java
double d = flag ? 1 : 0.5;   // double (int расширяется)
```

Осторожно с `null` и автоупаковкой:

```java
// Integer x = cond ? null : 5; // риск NullPointerException при распаковке
```

## Приоритет и ассоциативность операторов

| Приоритет (от высшего) | Операторы | Ассоциативность |
| --- | --- | --- |
| 1 | `()` `[]` `.` | слева |
| 2 | `++` `--` `~` `!` унарные `+` `-` | справа |
| 3 | `*` `/` `%` | слева |
| 4 | `+` `-` | слева |
| 5 | `<<` `>>` `>>>` | слева |
| 6 | `<` `>` `<=` `>=` `instanceof` | слева |
| 7 | `==` `!=` | слева |
| 8 | `&` | слева |
| 9 | `^` | слева |
| 10 | `\|` | слева |
| 11 | `&&` | слева |
| 12 | `\|\|` | слева |
| 13 | `?:` | справа |
| 14 | `=` `+=` `-=` … | справа |

Сомнительные места — заключать в скобки: `(a + b) * c` читается надёжнее, чем полагаться на приоритет.

## Условные конструкции

### `if`

```java
if (temperature > 30) {
    System.out.println("Жарко");
}
```

### `if-else`

```java
if (x >= 0) {
    System.out.println("Неотрицательное");
} else {
    System.out.println("Отрицательное");
}
```

### `else if`

```java
if (score >= 90) {
    System.out.println("A");
} else if (score >= 75) {
    System.out.println("B");
} else {
    System.out.println("C");
}
```

### Вложенные условия

```java
if (loggedIn) {
    if (isAdmin) {
        // доступ к админке
    }
}
```

Избыточную вложенность стоит упрощать ранним выходом (guard clauses):

```java
if (!loggedIn) return;
if (!isAdmin) return;
// основной код
```

## `switch`

### Классический `switch`

```java
switch (day) {
    case 1:
        System.out.println("Понедельник");
        break;
    case 2:
        System.out.println("Вторник");
        break;
    default:
        System.out.println("Другой день");
}
```

### `case`

Метка, сопоставляемая со значением выражения. В `case` можно перечислять несколько значений:

```java
case 1:
case 7:
    System.out.println("Выходной");
    break;
```

### `break`

Завершает выполнение `switch`, иначе управление «проваливается» в следующий `case` (fall-through). Пропущенный `break` — частый источник багов:

```java
switch (n) {
    case 1:
        System.out.println("один");  // без break выполнение пойдёт дальше
    case 2:
        System.out.println("два");
}
```

### `default`

Выполняется, если ни один `case` не совпал.

### Switch expressions

С Java 14 `switch` можно использовать как выражение, возвращающее значение:

```java
String result = switch (day) {
    case 1 -> "Понедельник";
    case 2 -> "Вторник";
    default -> "Другой день";
};
```

Не нужно `break` — каждый случай завершается сам.

### Стрелочный синтаксис `->`

```java
int numLetters = switch (month) {
    case "Январь", "Март" -> 31;
    case "Февраль" -> 28;
    default -> 30;
};
```

Блок в стрелочном синтаксисе требует `yield` для возврата значения.

### `yield`

Возвращает значение из блока стрелочного синтаксиса:

```java
int days = switch (month) {
    case "Февраль" -> {
        if (leapYear) yield 29;
        else yield 28;
    }
    default -> 30;
};
```

### Pattern matching в `switch`

С Java 21 `switch` поддерживает сопоставление с образцом по типу и `null`:

```java
Object obj = "hello";
String type = switch (obj) {
    case null      -> "null";
    case String s  -> "Строка длиной " + s.length();
    case Integer i -> "Число: " + i;
    case int[] a   -> "Массив из " + a.length;
    default        -> "Другой тип";
};
```

Доминирование (guarding) и `case` с условием:

```java
String r = switch (obj) {
    case String s when s.isEmpty() -> "Пустая строка";
    case String s -> "Строка: " + s;
    default -> "Другое";
};
```

Связано с pattern matching для `instanceof` — [[06. Наследование и полиморфизм#Полиморфизм|полиморфизм]].

## Циклы

### `while`

Проверяет условие перед каждой итерацией.

```java
int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}
```

### `do-while`

Выполняет тело минимум один раз, потом проверяет условие.

```java
int i = 0;
do {
    System.out.println(i);
    i++;
} while (i < 5);
```

### `for`

Инициализация, условие, шаг — в заголовке.

```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```

Несколько переменных через запятую:

```java
for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println(i + " " + j);
}
```

### Enhanced `for`

Перебор коллекций и массивов (см. [[10. Коллекции и структуры данных#Итераторы|итераторы]]).

```java
int[] arr = {1, 2, 3};
for (int x : arr) {
    System.out.println(x);
}
```

Примитивная итерация по элементам: если элемент меняется внутри цикла, исходный массив не меняется (копия).

### Вложенные циклы

```java
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        System.out.println(i + "," + j);
    }
}
```

## Операторы перехода

### `break`

Прерывает текущий цикл или `switch`.

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;   // выход из цикла
}
```

### `continue`

Пропускает остаток тела и переходит к следующей итерации.

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // пропустить чётные
    System.out.println(i);
}
```

### Метки (labeled break/continue)

Позволяют прерывать вложенные циклы целиком.

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 2) break outer;  // выход из обоих циклов
        System.out.println(i + "," + j);
    }
}
```

Использовать редко — обычно лучше вынести логику в метод с `return`.

### `return`

Завершает метод и возвращает значение (см. [[04. Методы и параметры#Объявление методов|объявление методов]]).

```java
int add(int a, int b) {
    return a + b;   // значение и выход из метода
}
```

В `void`-методе `return;` просто завершает выполнение.

# AGENTS.md — инструкции для ИИ-агента по этой базе знаний

## Что это за проект

База знаний по языку Java для Obsidian. Цель — энциклопедический справочник для разработчика с базовыми знаниями программирования. Ориентир — **Java 21 (LTS)**. Материал охватывает современный синтаксис (Java 8–21), устаревшие подходы упоминаются кратко и только как пояснение к старому коду.

## Структура файлов

- `01. … .md` … `18. … .md` — 18 заметок-глав. Имена в формате `NN. Название темы.md`.
- `0. Термины и определения.md` — глоссарий; не удалять, дополнять по мере появления новых терминов.
- `План.md` — исходный план глав и подразделов.
- `Содержание книги Java. Полное руководство.md` — справочное содержание книги; источник тем.
- `AGENTS.md` (этот файл) и `README.md` — мета-документация.

## Требования к заметкам

1. **Формат**: каждая заметка — отдельный `.md`, имена вида `NN. Название темы.md`.
2. **Оглавление**: ручной маркированный список вики-ссылок `[[#Заголовок|Заголовок]]` в начале каждой заметки.
3. **Заголовки**: без номеров. Иерархия `##` → `###` → `####` (иногда `#####`). Глубина не более 4 уровней.
4. **Содержание**: короткие рабочие примеры кода (5–15 строк), таблицы для сравнений, диаграммы Mermaid (classDiagram, flowchart, sequenceDiagram) для иерархий и потоков. Для подводных камней — показывать и неправильный, и правильный вариант.
5. **Связи**: перекрёстные вики-ссылки `[[Название заметки]]` или `[[Название заметки#Заголовок]]` там, где уместно.
6. **Стиль**: технический, без воды. Никаких вводных абзацев, целей и заключений — только суть.

## Договорённости

- Версия Java: **21 (LTS)**.
- Заметка «0. Термины и определения» — оставлять и обновлять.
- Заголовки разделов — **без номеров**.
- Оглавление — **ручной список вики-ссылок**.
- Темп генерации: **по одной заметке за ответ**, затем коммит.

## Подводные камни при работе с базой

- **Mermaid classDiagram**: имена классов не должны быть в кавычках с пробелами. `class "Примитивные типы"` → ошибка парсера. Пишите `class ПримитивныеТипы` (кириллица без пробелов работает).
- **Перекрёстные ссылки на заголовки**: если заголовок содержит inline-код (`` `static` ``), вики-ссылка должна указывать на заголовок **с** обратными кавычками: `[[#Ключевое слово `static`|static]]`. Obsidian матчит по очищенному тексту, но якорь в ссылке должен быть точным.
- **Проверка ссылок**: после изменений обязательно запускать скриптовую проверку: все межзамёточные ссылки (`[[Заметка]]`) и якорные (`[[Заметка#Заголовок]]`) должны вести на существующие файлы и заголовки. Глубина заголовков не должна превышать 5 `#`.
- **`classDiagram` наследование**: используйте `<|--` для отношения наследования, `..|>` для реализации интерфейса.

## Рабочий процесс агента

1. После одного полноценного изменения или создания заметки — коммит с коротким описанием на русском языке.
2. Генерировать заметки по одной (не пачками).
3. Проверять перекрёстные ссылки: они должны вести на существующие заметки и заголовки.
4. После заметок, где появляются новые термины, при необходимости дополнять `0. Термины и определения.md`.
5. Обновлять `README.md`, если меняется состав или структура базы.

## Объём базы

См. таблицу в `README.md` (18 заметок). Также в `README.md` есть раздел «Покрытие» с обоснованием исключения из базы AWT/Swing, сервлетов, JavaBeans и RMI — не пытайтесь добавлять эти темы без явной команды пользователя.
